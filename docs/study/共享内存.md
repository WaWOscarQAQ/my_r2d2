# 共享内存

## 定义

正常情况下，两个进程内存通过虚拟内存的方式相互隔离。共享内存是操作系统提供的一块公共区域。

一个进程写入，另一个进程读出。

在我们的项目中，C++ tracer 写 callback 事件，Rust 的 `TraceReader` 读取这些事件。

## Header 结构

header 主要存储了一些传输内容的摘要。包括：

```rust
pub struct TraceReader {
    file: File, // 文件指针
    reg_capacity: u64, // 注册事件的环形缓冲区大小
    rt_capacity: u64, // 运行时事件环形缓冲区大小
    reg_records_offset: u64, // 注册记录开始字节
    rt_records_offset: u64, // 运行时记录开始字节
    // cursor: 缓冲区游标
    reg_cursor: u64,
    rt_cursor: u64,
}
```

## Ring buffer

提供若干槽位，通过模拟循环使用：`slot = write_index % capacity`，相当于循环数组。
