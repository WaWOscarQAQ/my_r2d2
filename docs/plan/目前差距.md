这一项在当前 nav2_costmap_2d 目标上不能直接落，因为我刚核过 nav2_costmap_2d 目录里没有 action server 接面；也就是说，不是 sender 没写而已，是 live 目标本身没这个输入面。

所以，最小可落地顺序应该是：
